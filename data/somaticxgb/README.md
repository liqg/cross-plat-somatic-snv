# SomaticXGB feature matrices

These are the candidate-level feature matrices used to train and test SomaticXGB.

| File | Data rows | Columns | Positive / negative |
|---|---:|---:|---|
| `SomaticXGB_training_matrix_HG001-HG003.tsv.gz` | 493,937 | 27 | 66,972 / 426,965 |
| `SomaticXGB_test_matrix_HG004-HG005.tsv.gz` | 137,131 | 27 | 27,328 / 109,803 |

Both files are tab-separated and gzip-compressed. The first line is the header.

## Columns

The 27 columns are 17 model features plus candidate metadata and the label:

```
var, DP, ECNT, MPOS, NALOD, NLOD, MBQ_REF, MBQ_ALT, MFRL_REF, MFRL_ALT,
MMQ_REF, MMQ_ALT, TLOD, CHROM, POS, REF, ALT, c_p, label,
avg_mapping_quality, avg_basequality, avg_pos_as_fraction,
avg_num_mismatches_as_fraction, avg_sum_mismatch_qualities,
plat, reads, group
```

The 17 features used by the released model are:

```
DP, ECNT, MPOS, NALOD, NLOD, MBQ_REF, MBQ_ALT, MFRL_REF, MFRL_ALT,
MMQ_REF, MMQ_ALT, TLOD, avg_mapping_quality, avg_basequality,
avg_pos_as_fraction, avg_num_mismatches_as_fraction,
avg_sum_mismatch_qualities
```

Metadata columns:

- `var` — candidate identifier (`CHROM:POS:REF:ALT`).
- `CHROM`, `POS`, `REF`, `ALT` — candidate locus and alleles.
- `c_p` — `CHROM_POS` candidate key.
- `label` — 1 for a donor-private SNV target; 0 for a non-target candidate.
- `plat` — sequencing platform identifier (`FASTASeq_300`, `GenoLab_M`,
  `MGISEQ-T7`, `NovaSeq_6000`, `NovaSeq_X`, `SURFSeq_5000`).
- `reads` — raw target-average sequencing depth in millions of reads.
- `group` — training pair (`240730-train-test/12`, `13`, `21`, `23`, `31`,
  `32`) or test direction (`45` = HG004→HG005, `54` = HG005→HG004).

## Provenance

**Training matrix.** Built with `software/somaticxgb/R/build_feature_matrix.R`
from the six HG001–HG003 training pairs (`12`, `13`, `21`, `23`, `31`, `32`).
Each pair directory contains the pipeline-2 `config.json`, `mutect_a_vraw`
force-calling VCFs, `varscan` raw SNV calls, `varscan_novo` bam-readcount
outputs, and the position-frequency files referenced by `posfreq`.

**Test matrix.** Built from the 60 per-condition SomaticXGB prediction files
generated by the prediction stage (`workflow/somaticxgb/predict_SomaticXGB.R`)
for the two test directions HG004→HG005 (`45`) and HG005→HG004 (`54`), 30
conditions per direction. Each per-condition file contributes its 17 features,
candidate metadata and label; the assembled matrix has 137,131 rows and the
label counts above.

The earlier `dt_test_45_54.txt` (137,149 rows; 27,347 positive / 109,802
negative) is a previous-draft matrix and is **not** used here.

## Checksums

`SHA256SUMS` contains the checksums. From the repository root:

```bash
sha256sum -c data/somaticxgb/SHA256SUMS
```

## Data source

These matrices are derived from the public GIAB reference materials and the
sequencing data deposited under CNGBdb project CNP0009527. They contain
genomic coordinates and alleles from those public reference materials; no
individual participant data are included.
