- `Fig1a.png` / `Fig1a.pdf`: Fig. 1a PosMix workflow
- `Fig2a-c.png` / `Fig2a-c.pdf`: Fig. 2a-c simulation design

the manuscript project.  The PDFs were generated from the PNGs without
