# Supplementary figure source data

These are the derived tables read by
`analysis/07_figures_tables/make_bmc_supp_figures.py` to generate
Additional file 2 (Figs. S1-S12).  They were copied from the original
`response/addendum-analyses/tables/` directory so that a clean checkout can
regenerate the supplementary figures without the original analysis tree.

The exact figure-to-table mapping is documented in
`docs/figure_code_map.md`.
